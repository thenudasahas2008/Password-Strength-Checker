How it works

The checker uses simple educational heuristics. It considers length, character variety, common examples, repeated characters, and predictable sequences.

Important limitations

  • This score is not a guarantee of security.
  • It does not check breached-password databases.
  • Character variety alone does not make a password safe.
  • Prefer a long, unique password or passphrase and enable MFA.
